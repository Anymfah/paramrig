> Document autonome : un agent qui démarre sans contexte doit pouvoir l'exécuter de bout en bout. Le plan maître est `docs/scene-editor-plan.md` ; le prompt 1 (`docs/scene-editor-roadmap-prompt.md`) a été livré : ses règles, son protocole de QA et son architecture s'appliquent ici intégralement. L'état de référence est le code.

Dépôt : `/Users/soheil/Documents/repos/paramrig`, branche `main`, éditeur de scène dans `src/scene/`, servi sur `http://localhost:5174` par Docker Compose. Ce prompt livre le mode édition (Tab), ses trois modes de sélection, et l'ensemble des opérateurs de modélisation de Blender sur un maillage polygonal. Même exigence : rien de décoratif, chaque opérateur fonctionne et se rejoue dans le panneau « Adjust last operation », un commit par sous-chantier, `typecheck`, `lint`, `test`, `e2e -- scene-` et `git diff --check` avant chaque commit, bilan honnête à la fin.

## Chantier A · `EditMesh`, sélection d'éléments, superpositions

### A1 · Topologie
- `src/scene/mesh/editMesh.ts` : classe construite depuis `MeshData` en O(n) : tables sommet → arêtes, arête → faces (cycle radial), face → arêtes et boucles, `edgeKey(a, b)` sur ids. Requêtes : `vertEdges`, `edgeFaces`, `faceEdges`, `faceVerts`, `loopNext / loopPrev`, `otherVert`, `isBoundary(e)`, `isManifold(e)`, `isManifoldVert(v)`, `boundaryEdges()`, `linked(v)` (composante connexe), `edgeLoop(e)` (à travers les sommets de valence 4, s'arrête aux bords et aux pôles), `edgeRing(e)` (à travers les quads), `shortestPath(a, b)` (Dijkstra sur les sommets, arêtes ou faces), `faceNormal(f)` (Newell), `vertexNormal(v)`, `faceCenter(f)`, `faceArea(f)`, `dihedral(e)`, `bounds(ids)`, `median(ids)`. Mutations : `addVert(p)`, `addEdge(a, b)`, `addFace(loop)` (crée les arêtes manquantes, refuse une face dégénérée), `removeVert / Edge / Face` (cascade), `splitEdge(e, t)`, `splitFace(f, a, b)`, `joinFaces(f1, f2)`, `collapseEdge(e)`, `dissolveVert / Edge / Face`, `flipFace`, `setPos`. `toData()` renvoie un `MeshData` compact (emplacements compactés, ids conservés, `nextVertexId` monotone). `fingerprint.ts` : empreinte rapide (FNV sur positions et topologie) pour les caches.
- Tests : construction depuis chaque primitive, invariants (Euler sur les fermés, arêtes canoniques, radial cohérent), chaque mutation sur un cube et un plan subdivisé, `edgeLoop` sur un cylindre (fait le tour), `edgeRing` sur une grille (traverse), `shortestPath`, round-trip `toData` → `EditMesh` identique.

### A2 · Sélection
- `src/scene/mesh/selection.ts` : `ElementSelection = { vertices: Set<id>, edges: Set<edgeKey>, faces: Set<faceId>, active?: { kind, id }, history: Array<{ kind, id }> }` avec conversion entre modes selon Blender (sommets → arêtes dont les deux sommets sont sélectionnés → faces dont tous les sommets le sont ; retour d'un mode fin vers un mode grossier étend ; la conversion se fait au changement de mode, avec ⌃ pour « expand »), `selectMode: Set<'vertex' | 'edge' | 'face'>` (combinable avec ⇧ 1 / 2 / 3). Opérations pures : `selectAll / none / invert`, `more / less` (⌃+ / ⌃−, avec « face step »), `linked` (L au curseur, ⌃L de la sélection, par délimiteur seam / sharp / material / UV), `edgeLoop` (⌥ clic, ⇧⌥ étend), `edgeRing` (⌃⌥ clic), `shortestPath` (⌃ clic depuis l'actif, avec « fill region »), `boundaryLoop`, `loopInnerRegion`, `similar` (⇧G : par normale, aire, périmètre, matériau, nombre de côtés, longueur, direction, valence, seam, sharp…), `random`, `checkerDeselect` (nth, skip, offset), `byTrait` (non manifold avec ses options, loose, interior faces, faces by sides, sharp edges par angle), `sideOfActive` (⌃] ⌃[ par axe), `mirror` (⇧⌃M), `nextActive / previousActive`.
- Tests : chaque opération sur cube, cylindre, grille, tore (les boucles et anneaux font le tour et s'arrêtent où Blender s'arrête), conversion entre modes, historique de sélection (l'actif est le dernier ajouté ; retirer l'actif promeut le précédent).

### A3 · Mode édition dans le viewport
- Tab bascule objet ↔ édition sur l'objet actif et les objets sélectionnés (édition multi-objets : chaque objet garde sa sélection ; les opérateurs s'appliquent à chacun) ; ⌃Tab ouvre le camembert des modes. Le mode est dans `view` du document.
- Superpositions (`viewport/overlays.ts`) : sommets en `Points` avec shader de taille constante (glyphe 4 px, sélectionné 6 px, actif avec anneau), arêtes anticrénelées en `LineSegments2` (1 px, sélectionné 2 px en `--scene-edge-selected`, actif en blanc ; jamais `LineBasicMaterial`), faces avec teinte `--scene-face-selected` à 30 % et point central en mode face, le tout avec `polygonOffset` négatif et test de profondeur ; X-ray (⌥Z) coupe le test de profondeur et rend les faces à 50 %. Couleurs sensibles au thème et lisibles sur l'ombrage studio (contraste mesuré comme au prompt 1). Mise à jour incrémentale : un changement de sélection ne réécrit que l'attribut de couleur ; un déplacement de sommets pendant une geste ne réécrit que les positions ; la topologie ne se reconstruit qu'à l'empreinte.
- Prélèvement d'éléments (`viewport/picking.ts`) : passes d'ids pour faces (pleines), arêtes (lignes de 3 px dans la cible d'ids), sommets (points de 10 px) ; le survol lit la région et choisit sommet > arête > face dans le rayon de 10 px, sinon la face sous le curseur ; l'occlusion suit la profondeur, sauf en X-ray où boîte / lasso / cercle prennent aussi les éléments cachés. Survol en `--scene-hover`. Sélection : clic, ⇧ clic, boîte / cercle / lasso (nouveau, ⇧ ajouter, ⌃ retirer), clic dans le vide désélectionne (préférence). Priorité de clic sommet > arête > face testée à 4 zooms ; la sélection d'éléments survit à un aller-retour Tab et revient après un undo.
- Overlays du menu Overlays en édition : Edges, Faces, Face center, Creases, Sharp, Bevel weight, Seams, Vertex / edge / face normals (longueur réglable), Face orientation (bleu / rouge), Indices, Edge length / angle / face area (statistiques de mesure), Statistics dans la barre d'état (comptes sélectionnés / totaux).
- Sidebar N en édition : Item montre la médiane des sommets sélectionnés (Global / Local), éditable (déplace la sélection), et pour un seul sommet sa position.
- Tests : conversions de sélection au changement de mode ; e2e `scene-edit-mode` : Tab sur le cube, 1 / 2 / 3, clic sur un sommet (`pick` renvoie le bon id), ⇧ clic étend, ⌥ clic sur une arête sélectionne une boucle de 4 arêtes, boîte sur une moitié en X-ray sélectionne 4 sommets, A puis ⌥A, overlays activés visibles en capture, X-ray visible.

## Chantier B · Transformer des éléments

- `transform/session.ts` étendu aux éléments : cibles = sommets (les arêtes et faces sont réduites à leurs sommets), pivot médian / actif / individual origins (par îlot de sélection), orientation Normal (repère de la normale moyenne et de la tangente de l'arête active). G / R / S, G G glissement d'arête (`slide.ts` : chaque sommet glisse le long de ses arêtes adjacentes non sélectionnées, facteur −1 à 1, « even », « flipped », « clamp »), ⇧V glissement de sommet (le long d'une arête choisie par la direction du curseur), ⌥S rétrécir / gonfler le long des normales (« even thickness »), ⇧⌃⌥S cisaillement, ⇧⌥S to sphere ; Push / pull et Randomize (amount, uniform, normal, seed) sont des opérateurs du menu Transform.
- Édition proportionnelle (`transform/proportional.ts`) : O bascule, ⇧O type de falloff (smooth, sphere, root, inverse square, sharp, linear, constant, random), ⌥O connectés seulement, rayon à la molette pendant la session (cercle dessiné dans l'overlay), « projected from view ». Le poids de chaque sommet non sélectionné dérive de sa distance (euclidienne ou topologique via `shortestPath` pondéré) ; aussi en mode objet sur les objets.
- Aimantation (`transform/snap.ts`) : ⇧Tab bascule, menu de l'en-tête : incrément, sommet, arête, face, volume, milieu d'arête, perpendiculaire d'arête ; cible closest / center / median / active ; « project individual elements » (chaque sommet est projeté sur la surface la plus proche par lancer de rayon `three-mesh-bvh` sur les autres objets) ; « affect » move / rotate / scale ; l'aimantation par sommet et arête lit le tampon d'ids (éléments des autres objets et, en X-ray, de l'objet édité) ; l'indicateur d'aimantation se dessine dans l'overlay.
- Symétrie : X / Y / Z dans l'en-tête (miroir d'édition : le sommet symétrique, trouvé par position avec tolérance, suit chaque déplacement), auto-merge (fusion des sommets qui arrivent sur un autre sommet à la fin de la session, seuil réglable), « split edges & faces ».
- Tests unitaires : glissement d'arête sur un cylindre (les sommets restent sur les génératrices), falloff de chaque type (poids aux distances 0, rayon / 2, rayon), aimantation par incrément avec ⇧, symétrie sur un cube dont on déplace un sommet, auto-merge qui réduit le compte de sommets. e2e `scene-edit-transform` : G Z 1 sur une face, G G sur une arête, O avec molette, ⇧Tab puis aimantation d'un sommet sur un autre objet (positions égales dans le document), X symétrie.

## Chantier C · Extrude, inset, bevel

- **Extrude** (`operators/extrude.ts`) : E = extrude region (faces : nouvelles faces latérales le long des arêtes de bord de la région, faces intérieures déplacées, la région reste connectée ; arêtes : nouvelles faces quads ; sommets : nouvelles arêtes) puis session de déplacement contrainte à la normale moyenne (libre avec un second appui sur l'axe) ; ⌥E menu : extrude faces along normals (chaque face suit sa normale, « offset even »), extrude individual faces, extrude manifold (les faces qui rentrent dans le volume sont dissoutes, comme Blender 2.9), extrude edges only, extrude vertices only, extrude repeat (steps, offset). ⌃ clic droit extrude vers le curseur (sommets et arêtes : le nouveau sommet va au point cliqué, projeté sur le plan de vue à la profondeur du dernier sommet ; « rotate source »). Une extrusion annulée en session laisse les éléments dupliqués comme Blender, sauf si la préférence « cancel removes extrusion » est active (ParamRig : active par défaut, documentée comme écart).
- **Inset** (`operators/inset.ts`) : I, session interactive : déplacement du curseur = épaisseur, ⌃ = profondeur, I à nouveau = individual, boundary, offset even, offset relative, edge rail, outset, select outer. Faces adjacentes traitées en région (une seule bordure) sauf individual.
- **Bevel** (`operators/bevel.ts`) : ⌃B arêtes, ⇧⌃B sommets, session : déplacement = width, molette = segments, P = profil, A = affect vertices / edges, C = clamp overlap, M = miter outer (sharp / patch / arc) et inner (sharp / arc), offset type (offset, width, depth, percent, absolute), harden normals, mark seam / sharp, loop slide, material index. Implémentation pour les sélections manifold : pour chaque sommet touché, un « vertex mesh » (n-gone quand un seul segment, grille de profil sinon), faces de bord entre les sommets, faces latérales reconstruites, le profil superellipse de Blender (0,5 = arc). Les cas non manifold refusent proprement avec un message d'état.
- Tests : cube E sur une face (+4 faces, +4 sommets, fermé, normales sortantes), extrude along normals sur deux faces adjacentes (les faces se séparent), individual, manifold sur une face rentrante, extrude d'un sommet isolé, extrude d'une boucle d'arêtes de bord d'un plan ; inset d'un cube entier (6 faces intérieures, 24 latérales), individual ; bevel de toutes les arêtes d'un cube à 1 segment → 26 faces, à 2 segments → comptes attendus, profil 1 = plat, clamp overlap qui borne la largeur, bevel de sommets d'un cube à 1 segment → 8 triangles et 6 octogones ; F9 rejoue chaque opérateur avec de nouveaux paramètres. e2e `scene-extrude-bevel` : E sur la face du dessus puis glisser, I, ⌃B avec molette, F9 change les segments, captures.

## Finition exigée pour ce prompt, vérifiée avant livraison

Chaque point a sa preuve dans le bilan ; les règles générales sont dans la section 7 du plan, et la définition d'un opérateur « fini » s'applique aux quelque quatre-vingts opérateurs de ce prompt, sans exception.

- Chaque opérateur modal (E, I, ⌃B, ⌃R, K, G G, ⌥S, spin, bisect…) a son en-tête modal qui liste les touches actives, son HUD en DOM, Pointer Lock quand il est lancé au clavier, Escape et clic droit qui restaurent, F9 qui le rejoue, ⇧R qui le répète.
- Loop cut : la prévisualisation suit le survol sans latence perceptible (sous 4 ms sur 10 000 faces) ; knife : la ligne, les points posés et les points d'aimantation sont visibles et distincts ; bevel : la molette change les segments sans à-coup, le HUD dit « Width 0.12 m · Segments 3 · Profile 0.5 ».
- Overlays : sommets, arêtes, faces anticrénelés, lisibles à 3:1 sur les ombrages disponibles et dans les deux thèmes, tailles de sommets réglables dans les préférences, X-ray sans z-fighting.
- Survol d'un élément dans la frame suivante ; priorité de clic sommet > arête > face > objet testée à 4 zooms ; boîte, cercle et lasso dessinés nets, avec le curseur adapté.
- Aucun opérateur ne casse un maillage : chaque test vérifie manifold ou bord attendu, ids stables, arêtes canoniques, aucune face dégénérée ; un opérateur qui refuse le dit dans un `StatusMessage`.
- Multi-objets en édition : chaque objet garde sa sélection, un indicateur discret dans l'en-tête dit combien d'objets sont en édition.
- La barre d'état enseigne le mode : « Select · ⇧ Extend · ⌥ Loop · ⌃ Path » et, pendant un opérateur, ses touches.
- 320 px : barre d'édition tactile (Mode, Select mode, Move, Rotate, Scale, Extrude, Delete, More…), cibles d'éléments à 44 px.
